# 无痛英语 EnglishLite

浏览器插件：内置 **6656 条**常用英语词汇和短句（人工精选 + 四级 CET4 词汇表），
随机把页面中的中文替换成英文，鼠标悬停可看中文释义 —— 在日常浏览中无痛积累常用英语。

## 安装（Chrome / Edge）

1. 打开 `chrome://extensions`（Edge 用 `edge://extensions`）
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择插件所在目录
4. 打开任意中文网页（新闻、论坛、知乎…），点工具栏插件图标打开弹窗，**打开主开关**后即可看到部分中文被替换成英文

> 提示：插件**默认关闭**，打开弹窗开关才生效；每次刷新页面随机结果不同。
> 悬停在英文单词上会显示中文释义。替换词使用 Times New Roman 字体，与正文中文区分。
> **改了代码后记得在扩展卡片点 ↻ 刷新，再刷新测试网页。**

## 词库

- **人工精选**：240 条高频交流词 + 常用短句（你好吗/很高兴认识你/辛苦了…）
- **四级词汇**：qwerty-learner 开源 CET4 词表（2607 词）的中文释义，清洗生成 6400+ 条
- 词条为「中文 → 英文」映射，覆盖网页常见表达
- 自定义：直接编辑 `words.js`，或改 `tools/build_words.js` 后重新构建
- 词库生成：`node tools/build_words.js`（源数据 `tools/data/cet4_raw.json`）

## 使用

点工具栏插件图标打开弹窗：

| 功能 | 说明 |
| --- | --- |
| 主开关 | **默认关闭**，打开后开始替换；关闭立即恢复原文 |
| 替换强度 | 5% ~ 60%，每次加载时随机替换的比例，默认 20% |
| 悬停显示中文 | 鼠标悬停在替换出的英文上显示原中文 |

## 原理

- `content.js` 遍历页面文本节点，用词库匹配中文词/短句，按强度概率随机替换
- **首字索引**：词库按中文首字建索引，只匹配文本中出现的汉字，6000+ 词库下
  2850 字长文本匹配仅 ~1ms
- **长词优先 + 去重叠**：防拆词（「大家好」优先于「大家」→ Hello everyone）
- 边界规则：两端不紧邻 ASCII 字母/数字（保护 URL/英文/数字串），允许汉字相邻
  （中文无分词，过严边界会让正文无法匹配）
- 跳过 `script/style/code/pre/textarea/input` 等不该动的区域
- `MutationObserver` 处理动态内容（SPA、懒加载、弹窗）
- 设置存 `chrome.storage.local`（本地，不依赖 Google 同步），启动即用默认设置生效，
  storage 读回后自动重扫应用用户强度
- **强度双向实时生效**：调整强度/开关时，先把已替换的英文恢复成中文原文，
  再按新设置重新随机 —— 调高实时变多、调低实时变少、关闭插件立即恢复页面
  （120ms 防抖，拖动滑块不卡）

## 文件

```
manifest.json      插件清单 (MV3)
words.js           词库（6656 条，可自行增删）
core.js            匹配/替换纯函数（首字索引，可在 node 中测试）
content.js         页面注入逻辑
popup.html/js      设置弹窗
icons/             图标
demo.html          演示页
tools/build_words.js   词库构建脚本（人工词库 + CET4 → words.js）
tools/self-test.html   无扩展环境的 DOM 自测页
tools/make_icons.py   图标生成脚本
test_core.js       核心逻辑单元测试（含性能用例）
```

## 不生效排查（按顺序）

1. **扩展加载了吗**：`chrome://extensions` 里应看到「无痛英语 EnglishLite」卡片。
   没有 → 点「加载已解压的扩展程序」重新选本目录。
2. **改了代码后必须刷新扩展**：扩展卡片上的 ↻ 刷新按钮，然后**刷新你要测试的网页**
   （已打开的页面不会自动注入脚本）。
3. **别用本地文件测试**：`demo.html` 是 `file://`，插件默认不注入。
   打开任意普通网站（百度、新闻站）测试；想用 demo.html 需在扩展详情里开启
   「允许访问文件网址」。
4. **页面要有词库词**：含「你好/谢谢/工作/时间」等常见词的页面才有明显效果，
   默认 20% 强度，多刷新几次看到不同结果。
5. **看报错**：测试网页按 F12 → Console，找 `[EnglishLite]` 开头的警告。

> 注意：插件设置存 `chrome.storage.local`（本地），不依赖 Google 账号同步，
> 国内网络下不会卡初始化。
